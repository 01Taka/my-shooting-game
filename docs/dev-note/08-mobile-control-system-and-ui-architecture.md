# スマホモードにおける操作体系・UIアーキテクチャ設計仕様

スマートフォン横画面（両手持ち）プレイにおける全操作コンポーネントの配置、人間工学的役割分担、マルチタッチ制御、およびステート連動を網羅した操作体系の最新完全仕様です。

---

## 1. 操作体系の全体レイアウト

解像度 **1600 × 900（16:9）** を基準とし、左右両手の親指可動域に合わせて各操作コンポーネントを空間的に完全分離しています。

```
┌──────────────────────────────────────────────────────────────┐
│ [UIScene: HP / SHIELD / BLINKゲージ / SCORE / WAVE]          │
│                                                              │
│                      [ゲームプレイ空間]                      │
│                                                              │
│                                           (BLINK) 画面右上角 │
│                                             1/4円扇形パッド  │
│                                            (半径 160px)      │
│                                                              │
│                                           [WEAPON]           │
│                                            十字武器選択      │
│                                            スティック        │
│                                                              │
│     (MOVE)                                                   │
│   移動バーチャル                                             │
│   スティック                 [LOCK-ON]            (FIRE)     │
│  (画面左半分全体)          スマート索敵      画面右下角       │
│                           スティック          1/4円扇形パッド │
│                                              (半径 240px)    │
│ ◀─── 左親指可動域 ───▶   ◀───────── 右親指可動域 ─────────▶ │
└──────────────────────────────────────────────────────────────┘
```

## 2. 操作コンポーネント一覧と仕様詳細

## 3. 各コンポーネントの挙動と設計思想

### ① 移動バーチャルスティック (`MOVE`)

- **配置**: 画面左半分（`pointer.x < width / 2`）。
- **パラメータ**:
  - デッドゾーン: `18px`
  - 最大半径: `100px`（ベース半径: `80px`, ノブ半径: `36px`）
- **操作性**:
  - スティックを倒した角度・強さ（force: 0.0〜1.0）に応じたアナログ移動。
  - **向き制御の連動**: ロックオン対象が存在せず、かつロックオンスティックを倒していない場合、自機は移動ベクトルの進行方向を向きます。
  - **Fixed / Dynamic 対応**: 設定に応じて、定位置固定または画面左半分をタッチした瞬間の位置に出現する追従モードを選択可能。

---

### ② 攻撃パッド (`FIRE`)

- **配置**: 画面右下の角 `(width, height)` を原点とする半径 240px の扇形（1/4円）。
- **判定**: `Math.hypot(width - pointer.x, height - pointer.y) <= 240`
- **操作性**:
  - **タップ**: 単発射撃。
  - **長押し（ホールド）**: 装備武器ごとの発射レート（Normal: 140ms, Spread: 280ms 等）に応じたフルオート連射。
  - **指の負担軽減**: 右下の画面角に大きく配置されているため、画面を見ずに親指の腹でブラインドタッチ可能。
  - **照準連動**: ロックオン中の敵がいる場合はその敵へ自動追尾、ターゲット不在時は機体正面へ発射。
  - **視覚フィードバック**: 押下中は高輝度ネオンピンク（透過度 0.35）に光り、ラベルの不透明度が 1.0 に上昇。

---

### ③ ブリンクパッド (`BLINK`)

- **配置**: 画面右上の角 `(width, 0)` を原点とする半径 160px の扇形（1/4円）。
- **判定**: `Math.hypot(width - pointer.x, pointer.y) <= 160`
- **発動条件**:
  1. **ブリンクメーター**: コスト 50%（最大ゲージ 100 のうち 50 以上）を保有していること。
  2. **機体状態**: 自機が移動中であること（静止中の暴発や意図しないワープを防止）。
  3. **クールダウン**: 直前発動から 180ms 経過していること。
- **挙動と演出**:
  - 現在の移動方向ベクトルに向かって距離 220px 瞬間テレポート。
  - 残像（アフターイメージ）、青白のワープライン、着地時のショックウェーブ、ワープ効果音が発生。
  - テレポート先の壁（ワールド境界）を自動クランプし、画面外への脱出を防止。
- **状態表示**:
  - メーターが足りている場合: シアン（青色）に発光。
  - メーター不足時: スレートグレーに減光し、タップしても無反応（視覚的に利用不可であることが一目でわかる）。

---

### ④ ロックオンスティック (`LOCK-ON`)

- **配置**: 画面右半分のうち、攻撃パッド・ブリンクパッド・武器スティックのいずれにも該当しないエリア。
- **動作モード**:
  1. **ドラッグ操作（60° 扇形索敵）**:
     - スティックを倒した方向を中心に、視野角 60°・最大距離 1000px 以内の最寄り敵をリアルタイム追尾。
     - カメラがスティック方向へ最大 280px 先行シフト（視界確保）。
     - スティック外周に赤い照準三角インジケーターを表示。
  2. **タップ操作（360° 全方位オートロック）**:
     - スティックを倒さずに短時間（<350ms）ポンとタップすると、画面内の全方位 360° から最も近い敵を即時ロックオン。
  3. **手ブレ補正（タイムバッファ方式）**:
     - **フリック（<160ms）**: 画面を弾いた瞬間、そのセッションで最初に捉えた敵（またはフリック方向の敵）を即時確定。
     - **通常ドラッグ（>=160ms）**: 指がガラス面から浮く 70ms 前の安定した照準履歴を採用し、指離し時のズレを防止。
  4. **永続追従 ＆ 撃破チェーン**:
     - 指を離してもターゲットは永続固定され、機体は自動で敵を向き続けます。
     - 対象を撃破すると、半径 480px 以内の最寄りの別の敵へ自動でターゲットが連鎖吸着。

---

### ⑤ 武器選択スティック (`WEAPON`)

- **配置**: 画面右側（`x: width - 150, y: height - 330`）。攻撃パッドの真上に隣接して配置。
- **パラメータ**:
  - ベース半径: `50px`
  - ノブ半径: `24px`
  - 最大半径: `60px`
  - デッドゾーン: `15px`
- **操作フロー**:
  1. **タッチ開始**: 自機の周囲に十字型の武器選択ラジアルHUD（`WeaponSelectHUD`）がポップアップ。
  2. **スティック倒し**: 倒した方向（上下左右）の武器スロットが拡大＆カラーハイライト。
     - **上 (`▲`)**: **NORMAL**（通常弾 / 連射バランス型）
     - **右 (`▶`)**: **SPREAD**（3WAY拡散ショット）
     - **下 (`▼`)**: **LASER**（貫通レーザー）
     - **左 (`◀`)**: **EXPLOSIVE**（着弾爆発弾）
  3. **指離し（Release）**: 選択中の武器に即座に切り替わり、決定音（SE）が鳴ってHUDがフェードアウト。
  4. **キャンセル**: デッドゾーン内（中心付近）で指を離すと、武器を変更せずにHUDを閉じる。

## 4. 人間工学（エルゴノミクス）とマルチタッチ制御

### 右親指の干渉ゼロ化（空間分離）

スマホ横画面ゲームで右手の親指に複数の役割（攻撃・回避・照準・武器切替）を持たせる場合、ボタンの押し間違いが最大の課題となります。本設計では以下の工夫により競合を排除しています。

```
画面右上角 [BLINK]  ─── 人差し指または親指を伸ばして押す緊急回避エリア
        │
        ▼
   [WEAPON]        ─── 攻撃の手を休めて武器を選ぶ中間エリア
        │
        ▼
   [LOCK-ON]       ─── 画面右中央の広い空間で自由にフリック・エイム
        │
        ▼
画面右下角 [FIRE]   ─── 親指の自然なホームポジション（最も押しやすい大面積）
```

### マルチタッチ（最大5点）の同時処理

`this.input.addPointer(5)` により、以下の複合操作が完全に並行処理されます。

- **移動しながら射撃**: 左親指で移動スティックを倒したまま、右親指で攻撃パッドをホールド連射。
- **射撃しながら緊急ブリンク**: 連射中に右手を一瞬右上へスライドしてブリンクパッドをタップし、即座に攻撃パッドへ戻る。
- **エイムしながら武器変更**: ロックオンが永続追従するため、エイムしたまま右親指を武器スティックへ移して武器を切り替えてもターゲットが外れない。

## 5. 入力モードの自動検知とPC対応

| 操作モード                         | トリガー                                    | UI表示                                 | 特徴                                                                                           |
| :--------------------------------- | :------------------------------------------ | :------------------------------------- | :--------------------------------------------------------------------------------------------- |
| **`mobile` (スマホモード)**        | 画面タッチ（`pointerType === "touch"`）     | 全スマホUI表示                         | 本ドキュメント記載の全操作体系が有効。                                                         |
| **`pcMobile` (PCスマホモード)**    | PC環境で設定「キーボード＆マウスモード」OFF | スマホUI表示（左スティックのみ非表示） | WASDで移動し、右側のスマホUI（攻撃・ブリンク・武器・ロックオン）をマウス左クリックで操作可能。 |
| **`keyboardMouse` (PC専用モード)** | PC環境で設定「キーボード＆マウスモード」ON  | 全コントローラーUI非表示               | マウスカーソル方向へ常時エイム、左クリック射撃、ホイール武器切替、Shiftブリンク。              |
