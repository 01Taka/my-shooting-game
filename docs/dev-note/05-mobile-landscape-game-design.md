# スマホ横画面ゲームにおける解像度・アスペクト比と操作系UX設計

スマートフォンを両手で横向きに持ってプレイすることを前提とした、画面比率・解像度・バーチャルコントローラーの人間工学的設計思想です。

---

## 1. なぜ 800x450（16:9 アスペクト比）を採用したのか？

### アスペクト比の選定

現在のスマートフォンの多くは 16:9 〜 20:9 のワイド画面です。  
旧来の `800x600`（4:3 比率）をスマホ横画面で表示すると、左右に巨大な黒帯（余白）が生まれてしまい、操作エリアが極端に狭くなります。

- **16:9（800x450）の採用理由**:
  1. iPhone や Android を横にした際、画面いっぱいに無駄なく収まる。
  2. 画面の左右両端に「操作用コントローラー」を配置する十分な横幅が確保できる。
  3. 中央のゲームプレイ領域がコントローラーで遮られにくい。

---

## 2. バーチャルコントローラーの人間工学的配置

スマホ横画面ゲームでプレイヤーが最もストレスを感じるのは、「指が画面を隠してしまうこと」と「操作ボタンが指の可動域から外れていること」です。

```
┌──────────────────────────────────────────────┐
│ [UIScene: HP/Score]                          │
│                                              │
│               [ゲームプレイ領域]               │
│                                              │
│                                              │
│     ▲                                (SHOT)  │
│  ◀  ●  ▶                                     │
│     ▼                                        │
│ [左親指の可動域]                    [右親指の可動域]│
└──────────────────────────────────────────────┘
```

### 設計上の配慮

1. **左親指のホームポジション**:
   画面左下から少し内側（`x: 100, y: height - 100`）に十字キー（D-Pad）を配置。親指の自然な角度で上下左右にスライドできます。
2. **右親指のアクションポジション**:
   画面右下（`x: width - 90, y: height - 90`）に少し大きめの円形ボタン（半径40px）を配置。ブラインドタッチでも確実に押せるサイズにしています。
3. **マルチタッチ（2本指以上）の必須対応**:
   `this.input.addPointer(2)` を実行することで、**「左親指で十字キーを押しながら、同時に右親指でショットボタンを連打する」** という操作が途切れることなく動作するように保証しています。
