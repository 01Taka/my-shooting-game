# スマホ横画面ゲームにおける解像度・アスペクト比と操作系UX設計

スマートフォンを両手で横向きに持ってプレイすることを前提とした、画面比率・高解像度化（1600x900）・バーチャルコントローラーの人間工学的設計思想です。

---

## 1. なぜ 1600x900（16:9 アスペクト比）を採用したのか？

### アスペクト比 16:9 の必然性

現在のスマートフォンの多くは 16:9 〜 20:9 のワイド画面です。  
旧来の 4:3 比率（800x600等）では左右に巨大な黒帯が生じますが、16:9 なら画面いっぱいに無駄なく収まり、左右両端に指で操作するコントローラーエリアを十分に確保できます。

### 800x450 から 1600x900 への解像度引き上げの意思決定

- **初期構成（800x450）の課題**:
  基準解像度が 800x450 だと、現代のRetinaディスプレイやフルHDスマホ（横幅 2000px 超）に `Scale.FIT` で拡大された際、キャンバスの物理解像度が低すぎて文字やスプライトの輪郭が拡大ぼやけを起こしていました。
- **1600x900 への引き上げ効果**:
  1. キャンバスの物理ピクセル数が **4倍（36万 ➔ 144万画素）** に激増。
  2. 近年のスマートフォンの物理ピクセル密度に極めて近づき、文字もスプライトも一切のぼやけがなくクッキリ描画される。
  3. 16:9 の縦横比を完全に維持しているため、画面レイアウトのバランスを崩さずに高精細化できる。

---

## 2. バーチャルコントローラーの人間工学的配置 (1600x900)

スマホ横画面ゲームでプレイヤーが最もストレスを感じるのは、「指が画面を隠してしまうこと」と「操作ボタンが指の可動域から外れていること」です。

```
┌──────────────────────────────────────────────┐
│ [UIScene: HP/Score]                          │
│                                              │
│               [ゲームプレイ領域]               │
│                                              │
│                                              │
│     ▲                                (SHOT)  │
│  ◀  ●  ▶                                     │
│     ▼                                        │
│ [左親指の可動域]                    [右親指の可動域]│
└──────────────────────────────────────────────┘
```

### 設計上の配慮 (1600x900 スケール)

1. **左親指のホームポジション**:
   画面左下（`x: 180, y: height - 180`）に十字キー（ボタンサイズ 76px）を配置。親指の自然な角度で上下左右にスライドできます。
2. **右親指のアクションポジション**:
   画面右下（`x: width - 160, y: height - 160`）に大きめの円形ボタン（半径 72px）を配置。ブラインドタッチでも確実に押せるサイズにしています。
3. **マルチタッチ（2本指以上）の必須対応**:
   `this.input.addPointer(2)` を実行することで、**「左親指で十字キーを押しながら、同時に右親指でショットボタンを連打する」** という操作が途切れることなく動作するように保証しています。
